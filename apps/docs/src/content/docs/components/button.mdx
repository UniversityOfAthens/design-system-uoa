## Δομή

1. **Περιέκτης**: `<button>` ή `<a>` με `.uoa-button`. Φέρει το φόντο, το περίγραμμα και τον δακτύλιο εστίασης.
2. **Εικονίδιο** (προαιρετικό): inline SVG με `.uoa-button__icon`, πριν ή μετά την ετικέτα.
3. **Ετικέτα**: απλό κείμενο. Υποχρεωτική, εκτός από τα κουμπιά μόνο με εικονίδιο, που χρειάζονται `aria-label`.

## Οδηγίες

### Πότε να το χρησιμοποιείτε

- Για την κύρια ενέργεια μιας σελίδας ή φόρμας (υποβολή, αίτηση, εγγραφή).
- Για ενέργειες που αλλάζουν κάτι: αποθήκευση, διαγραφή, λήψη, άνοιγμα διαλόγου.
- Για σύνδεσμο που πρέπει να ξεχωρίζει, π.χ. «Αιτήσεις» στη σελίδα εισαγωγής.

### Πότε να μην το χρησιμοποιείτε

- Για πλοήγηση μέσα σε κείμενο: χρησιμοποιήστε απλό σύνδεσμο.
- Για πολλές ισότιμες επιλογές: χρησιμοποιήστε κουμπιά επιλογής (radio) ή λίστα (select).
- Για εναλλαγή προβολών στην ίδια σελίδα: χρησιμοποιήστε Καρτέλες (δεν υπάρχουν ακόμη).
- Για περισσότερα από ένα κύρια κουμπιά στην ίδια περιοχή. Διαλέξτε ένα και κάντε τα υπόλοιπα δευτερεύοντα ή τριτεύοντα.

### Παραλλαγές

| Παραλλαγή | Κλάση | Χρήση |
| --- | --- | --- |
| Κύριο | `.uoa-button` | Η μία κύρια ενέργεια μιας περιοχής |
| Δευτερεύον | `.uoa-button--secondary` | Άλλες ενέργειες δίπλα σε ένα κύριο |
| Τριτεύον | `.uoa-button--tertiary` | Ενέργειες χαμηλής έμφασης (ακύρωση, επαναφορά) |
| Μικρό | `.uoa-button--sm` | Πυκνό UI: φίλτρα, γραμμές πινάκων. Όχι για κύριες ενέργειες |
| Πλήρες πλάτος | `.uoa-button--block` | Όλο το πλάτος, π.χ. φόρμες σύνδεσης και κινητά |

### Περιεχόμενο

- Ξεκινήστε με ρήμα ή ουσιαστικό ενέργειας που λέει τι θα γίνει: «Υποβολή αίτησης», «Λήψη PDF», όχι «OK» ή «Εδώ».
- Κρατήστε την σύντομη, περίπου 1–3 λέξεις. Οι ελληνικές ετικέτες είναι 20–30% μακρύτερες από τις αγγλικές, οπότε ελέγξτε ότι χωρούν.
- Κεφαλαίο μόνο το πρώτο γράμμα. Μη χρησιμοποιείτε `text-transform: uppercase`: τα ελληνικά χάνουν τους τόνους και οι αναγνώστες οθόνης μπορεί να τα διαβάσουν λάθος.

### Συμπεριφορά

- Καταστάσεις: hover (σκουρότερο γέμισμα και λίγο μεγαλύτερη σκιά, ή απόχρωση), active (πάτημα 1px), focus-visible (δακτύλιος 3px), disabled (αδιαφάνεια 50%, χωρίς hover).
- Το κουμπί ψηλώνει αν η ετικέτα αναδιπλωθεί.
- Ελάχιστη περιοχή αφής 44 × 44px στο κανονικό μέγεθος και ύψος 36px στο `--sm`. Και τα δύο ξεπερνούν το ελάχιστο των 24px του WCAG 2.2.
- Η κατάσταση φόρτωσης δεν υπάρχει ακόμη.

## Προσβασιμότητα

- Χρησιμοποιήστε `<button type="button|submit">` για ενέργειες και `<a href>` για πλοήγηση. Ποτέ `<div>` ή `<span>`.
- Πληκτρολόγιο:

  | Πλήκτρο | Ενέργεια |
  | --- | --- |
  | `Tab` | Μεταφέρει την εστίαση στο κουμπί |
  | `Enter` | Ενεργοποιεί (κουμπί και σύνδεσμο) |
  | `Space` | Ενεργοποιεί (μόνο `<button>`) |

- Τα κουμπιά μόνο με εικονίδιο χρειάζονται `aria-label`. Τα διακοσμητικά εικονίδια παίρνουν `aria-hidden="true" focusable="false"`.
- Προτιμήστε να αφήνετε το κουμπί ενεργό και να δείχνετε σφάλμα επικύρωσης αντί να το απενεργοποιείτε. Ένα απενεργοποιημένο κουμπί δεν δέχεται εστίαση, άρα ο χρήστης δεν μπορεί να μάθει γιατί είναι ανενεργό.
- Ένα απενεργοποιημένο `<a>` έχει `aria-disabled="true"` και καθόλου `href`.
- Δεν χρειάζεται JavaScript.
- Στη λειτουργία υψηλής αντίθεσης των Windows, τα γεμάτα κουμπιά κρατούν ορατό περίγραμμα.
- Το ανοιχτόχρωμο περίγραμμα του δευτερεύοντος κουμπιού είναι διακοσμητικό: η ετικέτα αναγνωρίζει το στοιχείο (το WCAG 1.4.11 δεν απαιτεί περίγραμμα 3:1 όταν το κείμενο αρκεί).
- Δεν έχει γίνει ακόμη δοκιμή με αναγνώστες οθόνης (NVDA, VoiceOver).

## API

### HTML / CSS

`.uoa-button` + προαιρετικά `--secondary | --tertiary`, `--sm`, `--block`· παιδί `.uoa-button__icon`.
Απενεργοποίηση με `[disabled]` ή `[aria-disabled="true"]`.

### JavaScript

Καμία.

### Προσαρμογείς πλατφορμών

Θα συμπληρωθεί όταν επιλεγεί ο πρώτος προσαρμογέας (ADR 0003).

## Σχετικά

- Σύνδεσμος: για πλοήγηση μέσα σε κείμενο.
- Καρτέλες (προγραμματισμένο): για εναλλαγή προβολών.
