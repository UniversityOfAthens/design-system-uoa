## Δομή

1. **Περιέκτης**: `<div class="uoa-tabs" data-uoa-tabs>`.
2. **Λίστα**: `<div class="uoa-tabs__list">` με `aria-label` που ονομάζει το σύνολο.
3. **Καρτέλες**: `<button type="button" class="uoa-tabs__tab">` με μοναδικό `id` και `aria-controls` προς το πάνελ.
4. **Πάνελ**: `<section class="uoa-tabs__panel">` με μοναδικό `id`, `aria-labelledby` προς την καρτέλα και `tabindex="0"`.
   Η πρώτη καρτέλα είναι ενεργή — η σειρά του markup ορίζει την προεπιλογή.

## Οδηγίες

### Πότε να τις χρησιμοποιείτε

- Για εναλλαγή μεταξύ ισοδύναμων προβολών στο ίδιο σημείο: κατηγορίες, γλώσσες, εξάμηνα.
- Όταν ο χρήστης χρειάζεται μόνο μία προβολή κάθε φορά και οι άλλες μένουν διαθέσιμες.

### Πότε να μην τις χρησιμοποιείτε

- Για στοίβαξη ανεξάρτητων ενοτήτων που διαβάζονται σειριακά: χρησιμοποιήστε ακορντεόν.
- Για κύρια πλοήγηση μεταξύ σελίδων: χρησιμοποιήστε μενού πλοήγησης.
- Για κρίσιμο περιεχόμενο που πρέπει να φαίνεται χωρίς κλικ.
- Για μία μόνο προβολή: δείξτε την κατευθείαν, χωρίς καρτέλες.

### Παραλλαγές

Μία παραλλαγή: οριζόντιες καρτέλες με αυτόματη ενεργοποίηση (η εστίαση επιλέγει).
Σε στενές οθόνες η λίστα κυλά οριζόντια.

### Περιεχόμενο

- Ετικέτες σύντομες, μία ή δύο λέξεις, παράλληλης δομής: «Πρόγραμμα · Εγγραφές · Υποτροφίες».
- Κάθε πάνελ αυτοτελές, με τον δικό του τίτλο όταν είναι μεγάλο.
- Τα `id` μοναδικά ανά σελίδα — δύο ομάδες δεν μοιράζονται ποτέ `id`.

### Συμπεριφορά

- Χωρίς JavaScript: τα κουμπιά δεν κάνουν τίποτα και όλα τα πάνελ μένουν ορατά — τίποτα δεν χάνεται.
- Με JavaScript: αυτόματη ενεργοποίηση — βέλη, Home/End και κλικ επιλέγουν αμέσως.
- Μόνο η ενεργή καρτέλα είναι στο Tab order (roving tabindex)· τα ανενεργά πάνελ κρύβονται με `hidden`.

## Προσβασιμότητα

- Ρόλοι `tablist`/`tab`/`tabpanel`, `aria-selected` και roving tabindex προστίθενται από το `tabs.js`
  (WAI-ARIA tabs pattern, αυτόματη ενεργοποίηση).
- Χειρισμός πληκτρολογίου:

  | Πλήκτρο | Ενέργεια |
  | --- | --- |
  | `←` / `→` | Προηγούμενη / επόμενη καρτέλα (αντεστραμμένα σε RTL) |
  | `Home` / `End` | Πρώτη / τελευταία καρτέλα |
  | `Tab` | Έξοδος από τη λίστα προς το ενεργό πάνελ |

- Η λίστα χρειάζεται `aria-label` (γράφεται στο markup, στα Ελληνικά ή Αγγλικά).
- Τα πάνελ έχουν `tabindex="0"` ώστε να είναι προσβάσιμα με πληκτρολόγιο όταν το περιεχόμενο ξεχειλίζει.
- Στη λειτουργία υψηλής αντίθεσης των Windows η γραμμή της λίστας και η ένδειξη ενεργής καρτέλας μένουν ορατές.
- Δεν έχει γίνει ακόμη δοκιμή με αναγνώστες οθόνης (NVDA, VoiceOver).

## API

### HTML / CSS

`.uoa-tabs` (+ `[data-uoa-tabs]`)· παιδιά `.uoa-tabs__list` (`aria-label`), `.uoa-tabs__tab`
(`id` + `aria-controls`), `.uoa-tabs__panel` (`id` + `aria-labelledby` + `tabindex="0"`).

### JavaScript

`tabs.js` (είσοδος: `@uoa/core/js`): `init(root)` συνδέει κάθε `[data-uoa-tabs]` που δεν έχει
συνδεθεί· τρέχει αυτόματα στο φόρτωμα. Εξάγει και `select(group, tab, focus)` για προσαρμογείς.

| Επιλογή / μέθοδος / γεγονός | Τύπος | Περιγραφή |
| --- | --- | --- |
| `data-uoa-tabs` | attribute | Ο περιέκτης που γίνεται ομάδα καρτελών |

### Προσαρμογείς πλατφορμών

Θα συμπληρωθεί όταν επιλεγεί ο πρώτος προσαρμογέας (ADR 0003).
