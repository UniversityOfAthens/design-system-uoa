## Typefaces

| Role | Font | Token |
| --- | --- | --- |
| Display and `h1` | **Katsoulidis** (serif, 400/700) → Georgia | `--uoa-font-family-display` |
| `h2`–`h6`, body, UI | **Open Sans** (variable, 300–800) → system sans | `--uoa-font-family-heading`, `--uoa-font-family-body` |
| Code | System monospace | `--uoa-font-family-code` |

Both cover Latin and monotonic Greek. Neither has polytonic Greek. Katsoulidis files are not in
the repository until the licence for web use is confirmed; without them, Georgia is used.

## Scale

`display`, `heading-1`, `heading-2` and `heading-3` are fluid: they grow with the viewport
between the two sizes shown. Resize the window to see them change.

## Rules for Greek

- **No `text-transform: uppercase` on Greek.** Uppercase Greek drops its accents; CSS only does it
  correctly when `lang="el"` is set, and screen readers may spell out the result. Write the text in
  the case you want instead.
- **Headings keep a line height of at least 1.1.** Accented capitals (Ά, Έ, Ή) need the room.
- **Test with long words.** Greek runs 20–30% longer than English; headings use
  `text-wrap: balance` to avoid a single word on the last line.
