## Γραμματοσειρές

| Ρόλος | Γραμματοσειρά | Token |
| --- | --- | --- |
| Display και `h1` | **Katsoulidis** (serif, 400/700) → Georgia | `--uoa-font-family-display` |
| `h2`–`h6`, κείμενο, UI | **Open Sans** (variable, 300–800) → sans του συστήματος | `--uoa-font-family-heading`, `--uoa-font-family-body` |
| Κώδικας | Monospace του συστήματος | `--uoa-font-family-code` |

Και οι δύο καλύπτουν λατινικά και μονοτονικά ελληνικά. Καμία δεν έχει πολυτονικό. Τα αρχεία της Katsoulidis
δεν βρίσκονται στο αποθετήριο μέχρι να επιβεβαιωθεί η άδεια χρήσης στο web· χωρίς αυτά χρησιμοποιείται η Georgia.

## Κλίμακα

Τα `display`, `heading-1`, `heading-2` και `heading-3` είναι ρευστά: μεγαλώνουν με το πλάτος της οθόνης
ανάμεσα στα δύο μεγέθη που φαίνονται. Αλλάξτε το μέγεθος του παραθύρου για να τα δείτε να αλλάζουν.

## Κανόνες για τα ελληνικά

- **Όχι `text-transform: uppercase` σε ελληνικό κείμενο.** Τα κεφαλαία ελληνικά χάνουν τους τόνους τους· το CSS
  το κάνει σωστά μόνο όταν υπάρχει `lang="el"`, και οι αναγνώστες οθόνης μπορεί να διαβάσουν το αποτέλεσμα γράμμα-γράμμα.
  Γράψτε το κείμενο με τα πεζά/κεφαλαία που θέλετε.
- **Οι επικεφαλίδες κρατούν ύψος γραμμής τουλάχιστον 1.1.** Τα τονισμένα κεφαλαία (Ά, Έ, Ή) χρειάζονται χώρο.
- **Δοκιμάστε με μεγάλες λέξεις.** Τα ελληνικά είναι 20–30% μακρύτερα από τα αγγλικά· οι επικεφαλίδες
  χρησιμοποιούν `text-wrap: balance` ώστε να μη μένει μία λέξη μόνη στην τελευταία γραμμή.
