## Ακτίνα γωνιών

Χρησιμοποιήστε τα σημασιολογικά tokens: `--uoa-radius-control` (8px) για κουμπιά και πεδία,
`--uoa-radius-surface` (12px) για κάρτες, ειδοποιήσεις και πλαίσια.

<ShapeTiles kind="radius" />

## Σκιά

Απαλή και σε στρώσεις. Χρησιμοποιήστε `sm` σε ηρεμία, `md` στο hover ή για ανυψωμένες κάρτες, `lg` για επικαλύψεις.
