Icons come from Google's [Material Symbols](https://icones.js.org/collection/material-symbols)
([Apache License 2.0](https://github.com/google/material-design-icons/blob/master/LICENSE)) and ship in the
`@uoa/icons` package. They are 24×24 SVGs that take the text colour (`currentColor`) and their size from
the font (`em`).

## Usage

An icon goes with a label; it rarely replaces one. If people would have to guess what it means, write the word.

### Sizes

`.uoa-icon--sm` (text size) inside text and links, `.uoa-icon` (1.25em) next to labels, `.uoa-icon--lg`
(1.5em) in icon-only buttons. Components with their own icon part (`.uoa-button__icon`,
`.uoa-alert__icon`) size it themselves.

### Style

- The **outline** variant (`*-outline`) is the default. Keep filled icons (`info`, `warning`, `error`,
  `check-circle`) for alerts and very small sizes.
- Don't mix in icons from other sets (Font Awesome, Bootstrap Icons) on the same page.
- Arrows and chevrons that mean "next/previous" take `.uoa-icon--directional`, so they flip in
  right-to-left text.
- The set has no social media logos; those will be added separately, following each platform's brand rules.

## Accessibility

- Every `<svg>` has `aria-hidden="true"` and `focusable="false"`. The icon itself is never announced.
- Every `<svg>` also has `fill="currentColor"`, so it takes the text colour even before the CSS loads.
- When an icon is the only content of a control, the accessible name goes on the control
  (`aria-label="Εκτύπωση σελίδας"` on the `<button>`), not on the SVG. Prefer a visible label where it fits.
- Icon colour is never the only carrier of meaning: an alert also has a title, an error also has text.
- Being `currentColor`, icons follow system colours in high-contrast mode (`forced-colors`).

## Including icons

**Inline SVG (recommended).** Copy `@uoa/icons/svg/<name>.svg` into the markup. It works without JavaScript,
with no extra request, on every platform: Twig `{{ source('@uoa_icons/close.svg') }}`, PHP
`file_get_contents()`, or as a React component.

**Sprite.** Serve `@uoa/icons/sprite.svg` from the same domain and reference the symbol:

```html
<svg class="uoa-icon" aria-hidden="true" focusable="false" fill="currentColor">
  <use href="/assets/uoa/sprite.svg#uoa-icon-mail-outline"></use>
</svg>
```

For tooling and docs, `@uoa/icons/icons.json` holds every icon as `{ name: { group, body } }`.

### Adding an icon

Find it on [icones.js.org](https://icones.js.org/collection/material-symbols), add its name to the right
group in `packages/icons/src/icons.js` and run `bun run build`. Names match Iconify's.
