Colours come in two tiers. **Semantic** tokens (`--uoa-color-text-default`, `--uoa-color-action-primary`)
say what a colour is for; components use only these. **Primitive** tokens are the raw palette
they point to.

Contrast is measured against white:
<span class="uoa-pill" data-level="aa">AA</span> text (4.5:1),
<span class="uoa-pill" data-level="ui">UI</span> borders and icons only (3:1),
<span class="uoa-pill" data-level="deco">Decorative</span> never for meaning.
The swatches follow the brand picker at the top; hex values and contrast are for the default theme.
