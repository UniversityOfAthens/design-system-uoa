## Structure

1. **Container**: `<article class="uoa-card">` — a self-contained item that could stand on its own.
2. **Image** (optional): `<p class="uoa-card__media">` with one `<img>` with `alt` and dimensions.
3. **Body**: `<div class="uoa-card__body">` with blocks in order:
   - `<p class="uoa-card__eyebrow">` — the category: "News", "Event", "Undergraduate course".
   - `<h3 class="uoa-card__title">` — the title, linking to the item's page. The heading level
     follows the page outline; the class carries the style.
   - `<p class="uoa-card__meta">` — date (`<time datetime="…">`), venue, codes, badges.
   - `<p class="uoa-card__text">` — one or two sentences of summary.
   - `<p class="uoa-card__footer">` — secondary links (email, PDF), with a **different**
     destination from the title.
4. **Horizontal**: `uoa-card--horizontal` for people — fixed-width photo at the side.

## Guidelines

### When to use

- For lists of similar items: news, events, staff, courses.
- When each item needs an image, a date or a summary before the click.
- Inside a grid: footers pin themselves to the bottom.

### When not to use

- For a single status message: use an alert.
- For a plain list of links with no summary: a link list is enough.
- For presenting a single item: write a normal article, not a card.

### Variants

| Variant | Structure | Use for |
| --- | --- | --- |
| News / event | image + linked title + `<time>` | Announcements, events with date and venue |
| Person | `--horizontal` + photo + email in the footer | Academic and administrative staff |
| Course | no image + code/ECTS + badge | Course catalogue |
| Static | title without a link | Notices that lead nowhere |

### Content

- Short titles, noun first: "Spring semester enrolment…", not "Click here…".
- One or two sentences of summary — the card previews, it doesn't narrate.
- Dates always with `<time datetime="…">` in ISO format, for machines and screen readers.
- `alt` text that says what the image shows; if the image is decorative, `alt=""`.

### Behaviour

- Static: no JavaScript. When the title is a link, the whole card clicks through to it.
- In a row of equal-height cards, the footer stays at the bottom.
- At 320px the horizontal card keeps a narrower side photo — no horizontal scrolling.

## Accessibility

- A card is an `<article>` with a heading and plain links — no roles, no ARIA.
- The stretched title link is read once; there are no duplicate links to the same destination.
- The focus ring shows on the title; footer links stay clickable above it.
- Dates meet at least 4.5:1 (muted grey on white).
- In Windows High Contrast mode the `CanvasText` border keeps the shape, since backgrounds and shadows are removed.
- Screen-reader testing (NVDA, VoiceOver) hasn't been done yet.

## API

### HTML / CSS

`.uoa-card` + optional `--horizontal`; children `__media`, `__body`, `__eyebrow`, `__title`,
`__meta`, `__text`, `__footer`.

### JavaScript

None.

### Platform adapters

Filled in once the first platform adapter is chosen (ADR 0003).
