## Structure

1. **Container**: `<div class="uoa-alert">`. Tinted background and a 4px bar in the variant colour on the inline-start edge.
2. **Icon** (recommended): inline SVG with `.uoa-alert__icon`, decorative.
3. **Title** (optional): `.uoa-alert__title` on a heading of the right level for the page, or on a `<p>`.
4. **Content**: `.uoa-alert__content` holds paragraphs, lists and links.
5. **Close button** (optional): `.uoa-alert__close` with `data-uoa-alert-close` inside a container with
   `data-uoa-alert-dismissible`. Needs `alert.js` — without JavaScript the message stays visible and the button does nothing.

## Guidelines

### When to use

- Information that applies to the whole page or task: registration dates, a service outage.
- The result of something the user just did: a form was submitted, changes were saved.
- An error summary at the top of a form, linking to each field with a problem.

### When not to use

- Errors about one field: show them next to the field (form error message, not built yet).
- News or announcements: use a news card or list.
- Promotional content: alerts lose their weight if they are used for everything.
- More than one or two per page. Combine messages instead.

### Variants

| Variant | Class | Use for |
| --- | --- | --- |
| Info | `.uoa-alert` | Neutral information, the default |
| Success | `.uoa-alert--success` | Something the user did worked |
| Warning | `.uoa-alert--warning` | Something the user should act on soon |
| Danger | `.uoa-alert--danger` | Something failed or is blocking |

### Content

- Lead with what happened or what to do: "Η αίτηση υποβλήθηκε", not "Επιτυχία!".
- Keep it to one or two sentences. Add a title only when there is more than one sentence.
- Say what the user should do next, and link to it.
- Don't rely on colour or the icon alone: the words must say whether it's an error, a warning or information.

### Behaviour

- Static by default: no dismiss button, no auto-hide. The dismissible variant
  (`data-uoa-alert-dismissible` + `alert.js`) removes the message from the page and fires a
  `uoa:alert:dismiss` event — only for low-importance messages, never for errors that must be read.
- The bar, background and icon follow the variant; body text stays the default text colour.
- Width follows its container. Put it inside the content column, not full-bleed.

## Accessibility

- Messages present when the page loads need **no role**: they are read in order with the page.
  Give them a heading (`.uoa-alert__title` on an `<h2>`/`<h3>`) when they matter, so they show up in the headings list.
- Messages **inserted later** with JavaScript need a live region that exists before the text is inserted:
  - `role="status"` for confirmations and information (polite).
  - `role="alert"` for errors that need attention now (assertive). Use sparingly.
- An error summary after a failed submit: move focus to it (`tabindex="-1"` and `focus()`) instead of, or as well as, `role="alert"`.
- Icons are decorative (`aria-hidden="true" focusable="false"`).
- Text and title colours meet 4.5:1 on their backgrounds (see [Colour → Feedback](../../foundations/colour/#feedback)).
- In Windows High Contrast mode the alert gets a full border, since backgrounds are removed.
- Screen-reader testing (NVDA, VoiceOver) hasn't been done yet.

## API

### HTML / CSS

`.uoa-alert` + optional `--success | --warning | --danger`; children `.uoa-alert__icon`,
`.uoa-alert__content`, `.uoa-alert__title`, `.uoa-alert__close`. Links inside inherit the text colour.

### JavaScript

`alert.js` (entry: `@uoa/core/js`): `init(root)` wires every `[data-uoa-alert-dismissible]` not yet wired;
auto-runs on load. Add `role="status"` or `role="alert"` yourself when inserting messages dynamically.

| Option / method / event | Type | Description |
| --- | --- | --- |
| `data-uoa-alert-dismissible` | attribute | The `.uoa-alert` container that can be dismissed |
| `data-uoa-alert-close` | attribute | The `.uoa-alert__close` button — its label (`aria-label`) is written in the markup, Greek or English |
| `uoa:alert:dismiss` | event (bubbles) | Fired on the container just before it is removed |
