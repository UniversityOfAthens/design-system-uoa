## Structure

1. **Container**: `<div class="uoa-accordion">` with `data-uoa-accordion` (many open) or
   `data-uoa-accordion="single"` (one open — needs `accordion.js`).
2. **Item**: `<details class="uoa-accordion__item">`. `open` sets which start open.
3. **Button**: `<summary class="uoa-accordion__trigger">` with the title (`.uoa-accordion__title`) and the chevron
   (`.uoa-accordion__icon`, decorative).
4. **Content**: `.uoa-accordion__panel` (> `.uoa-accordion__content`) holds paragraphs, lists and links.

## Guidelines

### When to use

- For frequently asked questions and answers.
- For sections of a long form or page where users scan titles first.
- For filters and advanced options not everyone needs.

### When not to use

- For critical information that must be read: don't hide it.
- For primary navigation: use a navigation menu.
- For short content that fits on screen: show it directly.
- For switching between equivalent views: use tabs.

### Variants

| Variant | Attribute | Use for |
| --- | --- | --- |
| Multiple | `data-uoa-accordion` | The default; users compare sections |
| Single | `data-uoa-accordion="single"` | Large sections, one at a time — needs JavaScript |

### Content

- Keep titles short, as questions or topics: "When does enrolment open?".
- Make each section self-contained: users can read one without the others.
- Start with one open section when there is an obvious first choice, otherwise all closed.

### Behaviour

- Without JavaScript everything works: toggling is native (`<details>`), with no animation.
- With JavaScript: smooth height animation and, in the single variant, auto-collapse of the others.
  Without JavaScript the single variant behaves as multiple — all content stays reachable.
- The chevron rotates 180° on the open section. Motion is disabled under `prefers-reduced-motion`.

## Accessibility

- `<summary>` is natively keyboard-accessible (Enter/Space) and correctly announced —
  no ARIA attributes or custom key handling needed.
- Don't put a heading inside `<summary>` at the wrong level: a `<span>` title is enough for short
  lists; for long pages with many sections, prefer headings wrapping the button.
- Chevrons are decorative (`aria-hidden="true" focusable="false"`).
- In Windows High Contrast mode the container border and dividers stay visible.
- Screen-reader testing (NVDA, VoiceOver) hasn't been done yet.

## API

### HTML / CSS

`.uoa-accordion` (+ `[data-uoa-accordion]` / `[data-uoa-accordion="single"]`); children `.uoa-accordion__item`
(`<details>`, `open` for initially open), `.uoa-accordion__trigger` (`<summary>`), `.uoa-accordion__title`,
`.uoa-accordion__icon`, `.uoa-accordion__panel`, `.uoa-accordion__content`.

### JavaScript

`accordion.js` (entry: `@uoa/core/js`): `init(root)` wires every `[data-uoa-accordion="single"]` not yet wired;
auto-runs on load. The multiple variant needs no JavaScript.

| Option / method / event | Type | Description |
| --- | --- | --- |
| `data-uoa-accordion="single"` | attribute | The container that auto-collapses the other sections |

### Platform adapters

#### WordPress (`packages/wordpress`, [ADR 0003](https://github.com/UniversityOfAthens/design-system-uoa/blob/develop/docs/adr/0003-wordpress-first-adapter.md))

The `uoa/accordion` block in the `uoa-blocks` plugin, with `uoa/accordion-item` inner blocks (one section each, any content). Titles are typed straight into the editor, where every section stays open.

| Attribute | Type | Default | What it does |
| --- | --- | --- | --- |
| `single` | boolean | `false` | `uoa/accordion`: one section open at a time (`data-uoa-accordion="single"`, loads `accordion.js`) |
| `title` | string | — | `uoa/accordion-item`: the section title |
| `open` | boolean | `false` | `uoa/accordion-item`: open when the page loads |

The block outputs the core reference HTML exactly, with no `wp-block-*` classes and no colour or spacing settings; `tests/phpunit/MarkupTest.php` checks it. It works on any theme: its styles come with the plugin.
