Σύστημα σχεδίασης

Tokens, base styles and components for every NKUA website. Switch brand and accent at the top to see a department's theme.

Colour

Semantic colours follow the site's brand. Contrast is measured against white: AA text, UI borders and icons only (3:1), Decorative never for meaning.

Palettes

Typography

Katsoulidis for h1 and display text, Open Sans for everything else. Sizes from h3 upwards scale with the viewport.
