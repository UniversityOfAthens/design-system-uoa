# Katsoulidis (headings)

Commercial font by T. Katsoulidis, published by Cannibal Fonts (www.fonts.gr).
The font files are **gitignored** until NKUA's licence for web use and
redistribution is confirmed. Without them, headings fall back to Georgia/serif.

Place these files in this folder to get the real font locally:

- `KatsMoRg.woff2` — Regular
- `KatsMoIt.woff2` — Italic
- `KatsMoBd.woff2` — Bold
- `KatsMoBI.woff2` — Bold Italic

Coverage: Latin + monotonic Greek. No polytonic Greek.
